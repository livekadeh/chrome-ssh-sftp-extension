Run as Standalone Window / Desktop App

You can run this extension outside of Chrome browser tabs in a clean, dedicated desktop application window without address bar or bookmarks.

💡 How to install as a Desktop App icon in Chrome:
  1. Click the 3 dots menu in Chrome (top-right corner).
  2. Go to Cast, save, and share (or More tools) → Create shortcut...
  3. Check the box "Open as window" and click Create.
  4. A desktop icon and taskbar app will be created to launch directly!
⚡

Interactive SSH Terminal

Full xterm-256color emulation, ANSI colors, tabs, custom themes, and complete Persian/BiDi shaping with right-click Copy/Paste.

📁

Advanced SFTP Explorer

Fast chunked uploads with live progress bar, drag & drop, in-browser file editor with Ctrl+S, permissions chmod, and rich context menu.

🔒

Local & Encrypted Storage

All server credentials and private keys are stored strictly in your browser local storage with JSON backup export/import.

🌐

High-Speed Bridge Server

Node.js ssh2 WebSocket bridge proxying raw SSH and SFTP streams with low latency, portable zero-config runners available.
