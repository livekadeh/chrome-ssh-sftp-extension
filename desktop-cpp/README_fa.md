# ⚡ کلاینت بومی دسکتاپ LiveKadeh (C++ و Webview به همراه سرور بریج داخلی)

نسخهٔ بومی، بسیار سبک، امن و فوق‌العاده سریع دسکتاپ برای **LiveKadeh SSH & SFTP Pro** با استفاده از زبان **C++ (استاندارد C++17)**، معماری **Webview بومی سیستم‌عامل** (Microsoft Edge WebView2 در ویندوز) و **سرور بریج داخلی مستقیم در C++** (بدون نیاز به Node.js).

```text
│   └── nlohmann/json.hpp

    ├── main.cpp           # نقطه ورود برنامه، مدیریت پنجره و چرخه حیات بریج داخلی
    ├── webview.h          # هدر مستقل و سبک C++ Webview
    ├── bridge_manager.hpp # بررسی وضعیت پورت بریج

    └── bridge/            # هسته سرور بریج داخلی C++
        ├── cpp_bridge_server.hpp   # سرور وب Mongoose و وب‌سوکت /ws
        ├── cpp_bridge_session.hpp  # مدیریت نشست‌های SSH و SFTP با libssh2
        ├── base64.hpp              # اینکود و دیکود Base64 محلی
        └── mongoose.c              # سورس سبک Mongoose
```

## 🛠️ راهنمای کامپایل

### ۱. کامپایل برای ویندوز با MinGW (تک‌دستور):
```bash
cd desktop-cpp
make windows
```
فایل اجرایی سبک `bin/LiveKadeh-SSH-SFTP.exe` به همراه سرور وب و وب‌سوکت داخلی تولید می‌شود.

### ۲. پکیج نهایی و آماده انتشار:
فایل فشردهٔ آماده نسخه ویندوز در مسیر زیر قرار دارد:
`dist/LiveKadeh-SSH-SFTP-Windows-Cpp-v1.5.1.zip` (حجم فقط **۱.۲ مگابایت**!)

## 💡 مکانیزم عملکرد سرور بریج داخلی (Embedded C++)
1. با باز شدن فایل `LiveKadeh-SSH-SFTP.exe`، سرور وب داخلی (Mongoose) روی پورت ۳۰۰۰ به صورت یکپارچه بالا می‌آید.
2. رابط کاربری (پوشه `assets`) بلافاصله بارگذاری می‌شود.
3. اتصال وب‌سوکت کلاینت (`ws://127.0.0.1:3000/ws`) مستقیماً توسط موتور ++C و کتابخانه بومی `libssh2` مدیریت می‌شود:
   - ترمینال شل تعاملی SSH
   - فایل منیجر SFTP (مشاهده، آپلود، دانلود، تغییر نام، ویرایش، حذف و تغییر مجوزها)
4. هیچ نیازی به نصب Node.js، NPM، یا باز بودن پنجره سیاه خط فرمان برای سرور بریج وجود ندارد.
